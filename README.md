# סלולטור - סימולטור עלויות חכם (OMEGA v12.0)

אפליקציית React מודרנית ויוקרתית שנועדה לסייע לעובדי מדינה לחשב ולדמות את העלויות האישיות שלהם במסגרת מכרז הסלולר החדש של שנת 2026. האפליקציה עברה שדרוג מקיף לארכיטקטורת **OMEGA v12.0** הכוללת מודולריזציה מלאה, תמיכה מתקדמת ב-Dark Mode ומערכת סנכרון בזמן אמת לגוגל שיטס.

## 🚀 תכונות עיקריות (v1.5)

- **סימולטור עלויות אישי:** חישוב מדויק של ההשתתפות העצמית החודשית בתלוש השכר.
- **מחשבון סיום מוקדם:** חישוב יתרת תשלומים וקנסות יציאה עבור עובדים המסיימים את ההתקשרות מוקדם, נתמך במטריצת חודשים דינאמית.
- **מחירון תחזוקה אינטראקטיבי:** השוואת עלויות השתתפות עצמית בנזקים לפי דרג ומכשיר.
- **המדריך הרשמי למכרז:** ריכוז נהלים, דגשים פיננסיים, SIM Only ומסלולים מיוחדים.
- **תמיכה מתקדמת ב-Dark Mode ללא הבהובים (FOUC):** לוגיקה ייחודית ב-`index.html` שקוראת את מטמון הדפדפן (`localStorage`) לפני טעינת React ומחילה את ה-Theme המוגדר בגוגל שיטס באופן מיידי.
- **רינדור טקסט חכם (RTL Multiline):** שימוש ב-`whitespace-pre-line` כדי לכבד שבירות שורות (Enter) שהוזנו על ידי אמרכלים ישירות בגוגל שיטס למסכי הדגשים והשאלות.
- **נגישות ותאימות משפטית מלאה (WCAG 2.1 Level AA):** עמידה מלאה בתקן ישראלי ת"י 5568, כולל פתרון בעיות ניגודיות, ניווט מקלדת מלא, אופטימיזציה לקוראי מסך, הצהרת נגישות תקנית, אפיון מלא בקובץ [CHARACTERIZATION.md](./docs/CHARACTERIZATION.md) ודוח מפורט למחלקה המשפטית בקובץ [ACCESSIBILITY_COMPLIANCE.md](./ACCESSIBILITY_COMPLIANCE.md).

## 🛠 טכנולוגיה וארכיטקטורה

- **Frontend:** React 19 + Vite
- **Styling:** Tailwind CSS + Custom Design System (Oklch)
- **Data Engine:** 
  - עבודה מול Google Sheets API (gviz) בתור CMS ללא צורך בשרת (Serverless).
  - **Fallback Engine:** במידה וגיליון מקור נופל או מוגבל גישה (Rate Limit), המערכת יורדת בצורה חלקה להשתמש במידע שמור מקומי (`fallbackData.js`), יחד עם הודעות מערכת המיידעות את המשתמש.
  - **Smart Caching:** שמירת נתונים לוקלית (Local Storage) למניעת קריאות מיותרות ושיפור זמני טעינה.
- **Icons:** Lucide React

## 🏗 מבנה הפרוייקט (Modular Architecture)

- `src/screens/`: מסכי האפליקציה (Calculator, Termination, Maintenance, Guide, Faq, ImportantNotes).
- `src/components/`: רכיבי ממשק משותפים.
- `src/sheetsService.js`: הלוגיקה וההמרה (Parsing) מול ה-gviz API, כולל פילטרים ומערכות מטמון.
- `src/useAppData.js`: Custom Hook המשמש לסנכרון State האפליקציה וניהול מצבי טעינה.
- `index.html`: כולל את לוגיקת טרום-הטעינה (Pre-hydration) לשליטה ב-Theme ומניעת הבהובים.

## 🏗 הרצה מקומית

1. התקנת תלויות: `npm install`
2. הרצה במצב פיתוח: `npm run dev`
3. בנייה ל-production: `npm run build`
