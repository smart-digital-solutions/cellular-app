# סלולטור - סימולטור עלויות חכם (OMEGA v12.0)

אפליקציית React מודרנית ויוקרתית שנועדה לסייע לעובדי מדינה לחשב ולדמות את העלויות האישיות שלהם במסגרת מכרז הסלולר החדש של שנת 2026. האפליקציה עברה שדרוג מקיף לארכיטקטורת **OMEGA v12.0** הכוללת מודולריזציה מלאה, תמיכה ב-Dark Mode וביצועים אופטימליים.

## 🚀 תכונות עיקריות (v1.5)

- **סימולטור עלויות אישי:** חישוב מדויק של ההשתתפות העצמית החודשית בתלוש השכר, תוך שקלול מדרג הזכאות המשרדי מול המכשיר הנבחר.
- **מחשבון סיום מוקדם:** חישוב יתרת תשלומים וקנסות יציאה עבור עובדים המסיימים את ההתקשרות לפני תום 24 חודשים.
- **מחירון תחזוקה אינטראקטיבי:** השוואת עלויות השתתפות עצמית בנזקים (שבר מסך, אובדן, גניבה) עם אפשרות לסינון לפי מכשיר ספציפי.
- **תמיכה מלאה ב-Dark Mode:** ממשק המגיב אוטומטית להגדרות המערכת, מבוסס על טוקני עיצוב (Design Tokens) בשיטת Oklch.
- **נגישות WCAG 2.2:** עמידה בתקני נגישות מחמירים, ניווט מקלדת מלא ותמיכה בקוראי מסך.

## 🛠 טכנולוגיות

- **Frontend:** React 19 + Vite
- **Architecture:** Modular Screen Decomposition
- **Styling:** Tailwind CSS + Custom Design System (Oklch)
- **State:** Google Sheets Live Sync (with Fallback Engine)
- **Icons:** Lucide React

## 🏗 מבנה הפרוייקט (Modular Architecture)

האפליקציה בנויה במבנה מודולרי המפריד בין לוגיקת הנתונים לבין התצוגה:

- `src/screens/`: מסכי האפליקציה המופרדים (Calculator, Termination, Maintenance, Guide, Faq).
- `src/components/`: רכיבי ממשק משותפים (OmegaSelect, Accordion, וכו').
- `src/services/`: שירותי תקשורת וסנכרון מול Google Sheets API.
- `src/config.js`: ריכוז הגדרות המערכת וקישורים חיצוניים.
- `src/index.css`: מערכת העיצוב המרכזית (Design System) התומכת ב-Light/Dark Mode.

## 🏗 הרצה מקומית

1. התקנת תלויות: `npm install`
2. הרצה במצב פיתוח: `npm run dev`
3. בנייה ל-production: `npm run build`
